EX-Expander

Productivity App • Windows Text Expansion Tool
Role

Independent developer and project lead; designed, built, and shipped the desktop application.

Tools

C++ • Win32 API • WebView2 • SQLite • Windows system tray integration

Problem

Typing repetitive text and snippets is slow and interruptive. Many productivity tools steal focus or require a separate editor, making expansion impractical in real-world Windows workflows.

Result

I created a lightweight Windows text expander that expands user-defined shortcodes anywhere, without stealing focus. It supports popup suggestions, app-scoped rules, clipboard-safe insertion, auto-start, and an embedded manager for organizing snippets.
